# My-Python-Learning-Journey
我的python学习仓库
## 项目简介
这是我的Python学习仓库，存放课堂练习代码。本项目包含两个简单Python程序，分别实现输入问候、奇偶数判断功能，用来练习基础输入输出、分支判断语法。

## 文件说明
- `第一个文件.py`：接收用户输入名字，输出问候语并完成加法运算，练习输入、输出与变量运算。
- `第二个文件.py`：接收一个整数，判断该数字是奇数还是偶数，练习if分支、取余运算。

## 代码说明
```python
# 第一个文件.py核心逻辑
name = input("请输入你的名字：")
print(f"你好，{name}！欢迎学习Python")
x = 6
y = 8
print(f"6 + 8 = {x + y}")

# 第二个文件.py核心逻辑
num = int(input("请输入一个整数："))
if num % 2 == 0:
    print(f"{num} 是偶数")
else:
    print(f"{num} 是奇数")
```
